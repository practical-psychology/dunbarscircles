## 🔍 Quick Reference

### Key Concepts

- **Dunbar's Number**: ~150 stable relationships humans can maintain
- **Five Levels**: Inner Circle (5) → Sympathy Group (15) → Affinity Group (50) → Active Network (150) → Recognition Group (500)
- **Local First**: Data is stored in your browser; cloud backup only if you sign in

### Essential Pages

- **Home** (`/`) - Overview and introduction
- **Tutorial** (`/onboarding`) - Interactive learning experience
- **Radial View** (`/radial`) - Concentric circles visualization
- **Network** (`/network`) - Interactive relationship graph
- **Contacts** (`/contacts`) - Manage relationships and import data

### Data Formats

- **Import**: Facebook JSON, LinkedIn CSV
- **Export**: PNG, SVG, JSON, CSV
- **Backup**: JSON format recommended
