# YAKW Quick Start Guide

## 🚀 Get Started in 5 Minutes

### Step 1: Understand the Basics

- **Dunbar's Number**: Humans can maintain ~150 stable relationships
- **5 Levels**: Inner Circle (5) → Sympathy Group (15) → Affinity Group (50) → Active Network (150) → Recognition Group (500)
- **Color Coding**: Red → Orange → Yellow → Green → Blue

### Step 2: Take the Tutorial

1. Go to [Homepage](/)
2. Click "Tutorial & Guide" button
3. Complete the 8-step interactive tutorial
4. Learn all features hands-on

### Step 3: Import Your Data (Optional)

1. Go to [Contacts](/contacts)
2. Click "Import Data"
3. Upload Facebook JSON or LinkedIn CSV
4. Review auto-categorization
5. Adjust as needed

### Step 4: Explore Visualizations

- **[Radial View](/radial)**: Concentric circles showing relationship levels
- **[Network Diagram](/network)**: Interactive graph of connections
- **[Levels](/levels)**: Detailed breakdown of each Dunbar level

### Step 5: Manage Relationships

- Add contacts manually in [Contacts](/contacts)
- Edit relationship details and categories
- Track contact frequency and relationship health
- Export your data for backup

## 🔧 Essential Controls

### Navigation

- **Theme Toggle**: Top-right corner (light/dark mode)
- **Page Navigation**: Use menu or direct URLs
- **Browser Back/Forward**: Works normally

### Visualizations

- **Click & Drag**: Pan around network diagrams
- **Mouse Wheel**: Zoom in/out
- **Node Click**: Select relationship levels
- **Hover**: Show detailed tooltips

### Data Management

- **Import**: Supports Facebook JSON, LinkedIn CSV
- **Export**: PNG, SVG, JSON, CSV formats
- **Backup**: Regular JSON exports recommended
- **Privacy**: All processing happens locally

## 🛡️ Privacy & Security

- ✅ **100% Local Processing** - No data sent to servers
- ✅ **No Registration Required** - Use immediately
- ✅ **No Tracking** - Your data stays private
- ✅ **Open Source** - Code available for review

## 🆘 Quick Troubleshooting

| Problem                  | Solution                                        |
| ------------------------ | ----------------------------------------------- |
| Import fails             | Check file format (JSON/CSV), try smaller files |
| Visualization won't load | Refresh page, try different browser             |
| Performance issues       | Close other tabs, clear browser cache           |
| Data disappeared         | Check browser storage, restore from backup      |
| Mobile display issues    | Rotate to landscape, use pinch-to-zoom          |
